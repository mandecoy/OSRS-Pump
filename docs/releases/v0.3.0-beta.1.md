## Added in this build

1. OSRS-styled dark stone, bronze and gold phone UI.
2. New Home dashboard and integrated market summary.
3. Markets hub with 23 distinct discovery categories, including fast flips, high margins, price comparisons, and volume windows.
4. Item image cards with profits after GE tax, ROI, source data freshness and trading volume.
5. Advanced filter sheet, K/M/B suffix parsing, minimum and maximum item price/profit/ROI/volume, buy limit, membership, freshness, capital and sorting.
6. One-tap filter presets and search by name or ID.
7. A 24-hour aggregate feed for comparisons, labelled as average price gaps rather than literal 24-hour change.
8. JavaScript automated tests for filtering, volume and discovery categories.

## Limitations

- Wiki prices are completed instant buy/sell transactions, **not** a live order book, sellable bids or guaranteed profit.
- Observed 1h average vs 24h average should not be interpreted as 24-hour start-to-end price return.
- Background Android notifications, curated crafting methods, death's coffer guide-price sourcing and real all-time historical extremes are still pending.
- Only the Android build and JavaScript checks were verified in CI; user-device smoke test remains outstanding.
- GitHub Actions debug-signed APKs may require a backup, uninstall and reinstall rather than an in-place update. Export JSON from Settings first.
