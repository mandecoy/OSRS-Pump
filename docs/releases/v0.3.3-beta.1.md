# OSRS Pump Android v0.3.3 beta 1 — Launcher icon correction

This version fixes the launcher icon **from the Android project source**. The Android manifest points to `@mipmap/ic_launcher`, which is an adaptive launcher icon containing the user's agreed teal-and-gold octagonal medallion artwork in `res/drawable-nodpi/ic_pump_foreground.png` on a black adaptive background. The old `ic_pump` vector is no longer referenced by the launcher. The GitHub build checks that the compiled APK packages the drawable and launcher XML and that the manifest resolves the launcher icon.

**Important:** Beta debug signatures can differ between GitHub Actions runs. Export all saved trade data from the old app before uninstalling and reinstalling if Android refuses an in-place upgrade.
